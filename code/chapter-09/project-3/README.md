# Project 3 — Goal-Governed Interpretive Variation

This project demonstrates that the same feeling-in-context can yield different emotions under different goals.

## Build
dotnet build

## Run

### Same feeling, performance goal
dotnet run -- backstage 8 perform_well

### Same feeling, avoidance goal
dotnet run -- backstage 8 avoid_failure

## Expected behavior
The same feeling state remains constant while the interpreted emotion changes with the goal.
