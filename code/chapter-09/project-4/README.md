# Project 4 — Phase-Separated Execution Flow

This project demonstrates a simple execution flow from external situation to feeling to goal-governed emotional meaning.

## Build
dotnet build

## Run

### Safety goal
dotnet run -- footsteps_behind stay_safe

### Friend goal
dotnet run -- footsteps_behind meet_friend

## Expected behavior
The same situation produces a feeling first. Emotional meaning appears only after goal-governed interpretation.
