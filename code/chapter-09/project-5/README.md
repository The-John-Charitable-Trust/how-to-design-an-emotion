# Project 5 — Reinterpretation and Revision

This project demonstrates that emotional meaning can be revised without changing the underlying feeling.

## Build
dotnet build

## Run

### Initial interpretation
dotnet run -- dark_street 7 stay_safe unknown_person

### Revised interpretation
dotnet run -- dark_street 7 stay_safe recognized_friend

## Expected behavior
The feeling remains constant while emotional meaning changes when contextual knowledge is updated.
