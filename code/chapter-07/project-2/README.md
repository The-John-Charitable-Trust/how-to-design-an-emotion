# Project 2 – Valid vs Invalid Instantiation

## Goal
Demonstrate that not all inputs can instantiate a concept. Meaning is constrained by admissibility conditions.

## Run Instructions

Valid:
dotnet run -- 7

Invalid:
dotnet run -- rock

## Expected Output

Valid:
Meaning: '7' refers to the value 7 (int) in the context of days in a week...

Invalid:
Result: INVALID INSTANTIATION - 'rock' is not a valid Integer.
