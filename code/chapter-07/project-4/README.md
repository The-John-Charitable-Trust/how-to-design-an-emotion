# Project 4 – Goal-Governed Interpretation

## Goal
Demonstrate that meaning depends on the interpreter’s goal, not just context.

## Run Instructions

dotnet run -- 7 "Determine how many days are in a week"
dotnet run -- 7 "Validate a weekly schedule"
dotnet run -- 7 "Compare calendar systems"

## Expected Output
Meaning varies based on goal while structure and context remain constant.
