# Project 1 – Integer Constructivist Semiotic Sign

## Goal
Demonstrate that meaning is generated through structured interpretation, not intrinsic to symbols.

## Setup
1. Install .NET SDK 6+
2. Navigate to Project1 folder

## Run
dotnet run

## Expected Output
Meaning: '7' refers to the value 7 (int) in the context of days in a week, for the goal of Determine how many days are in a week. Interpreter: Cezjah.
