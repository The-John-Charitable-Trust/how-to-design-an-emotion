# Chapter 2 - Project 1: Integer Concept and Construct

This project demonstrates the distinction between a concept and a construct using the simple case of an integer.

- The concept declares identity conditions: identifier type and value type.
- The construct realizes those identity conditions by assigning determinate runtime values.

Instructions for how to build and run the code can be found in: *How to Run the Code Examples in This Book*.

## Run Command

```bash
dotnet run -- "Seven" 7
```

## Expected Output

```text
Integer Concept
identifier type: string
value type: int

Construct Created
identifier: "Seven"
int value: 7

Result
The identifier names the construct; the concept declares the integer identity conditions.
Identity conditions remain fixed. Only the assigned value realizes the construct.
```
