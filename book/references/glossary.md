# Glossary

This glossary defines the terms I coin or use in a restricted sense. Each entry links to the chapter or appendix that defines the term. A print index is deferred to typesetting, when page numbers are fixed.

**affect (physiological affect).** The physiological and regulatory substrate, including valence, arousal, and motivational intensity, that generates the conditions of feeling without itself constituting feeling or emotion. See [Chapter 9](../part-4/chapter-09.md).

**CCME.** See *Constructivist Computational Model of Emotions*.

**CITE.** See *Constructivist Interpretation Theory of Emotion*.

**commitment.** The normative act by which an interpreter authorizes one interpretation as emotionally binding, so that it admits correctness, error, justification, and revision. See [Chapter 9](../part-4/chapter-09.md).

**Constructivist Computational Model of Emotions (CCME).** An executable specification of the CSME that tests its internal consistency by preserving its ontological distinctions in code. It is not an empirical test. See [Appendix J](../appendices/appendix-j.md).

**Constructivist Interpretation Theory of Emotion (CITE).** The theory that interpretation, not appraisal, constructs emotional meaning; it marks where appraisal ends and interpretation begins. See [Appendix K](../appendices/appendix-k.md).

**Constructivist Linguistics of Emotion.** The account of how emotional meaning acquires symbolic structure, public communication, and recognizable categories. See [Part V](../part-5/README.md) and [Chapter 10](../part-5/chapter-10.md).

**Constructivist Semiotic Model of Emotions (CSME).** A formal cognitive-semiotic architecture that specifies the constituents, relationships, and constraints through which an agent constructs emotional meaning. See [Chapter 9](../part-4/chapter-09.md).

**Constructivist Semiotic Sign (CSS).** A sign with five necessary constituents: interpreter, identifier, concept, construct, and referent. Interpretation is the act performed on the sign, not a sixth constituent. See [Chapter 7](../part-3/chapter-07.md).

**Constructivist Semiotics.** The cognitive-semiotic architecture that specifies the structural requirements for constructing meaning through the Constructivist Semiotic Sign. See [Chapter 7](../part-3/chapter-07.md).

**CSME.** See *Constructivist Semiotic Model of Emotions*.

**CSS.** See *Constructivist Semiotic Sign*.

**emotion.** A goal-governed, context-sensitive semiotic interpretive act by which an agent assigns meaning and significance to feeling. See [Chapter 9](../part-4/chapter-09.md).

**Emotional Constructivism.** The position that emotions are cognitive-semiotic constructions and, as its defining claim, that a rational agent can inspect and redesign the interpretive architecture that produces emotional meaning. See [Chapter 14](../part-5/chapter-14.md) and [Appendix L](../appendices/appendix-l.md).

**emotional grammar.** The rules by which an agent organizes feeling into intelligible emotional categories. It is not a fixed, mind-independent system. See [Chapter 13](../part-5/chapter-13.md) and [Appendix N](../appendices/appendix-n.md).

**Emotional Meaning Architecture.** A threshold model of ten levels, 0 through 9, from computational mapping and physiological activation to recursive emotional self-regulation. Level 5 marks detachable symbolic stabilization; Level 7 marks full emotional meaning. See [Chapter 11](../part-5/chapter-11.md).

**Emotionese.** The symbolic system through which agents construct, stabilize, and communicate emotional meaning. See [Chapter 10](../part-5/chapter-10.md).

**feeling.** The conscious metaperceptual awareness of a semiotically available affective experience with a distinctive affective character. See [Chapter 9](../part-4/chapter-09.md).

**identity conditions.** The constraints, specified at a concept’s constraint layer, that an instance must satisfy to count as admissible. See [Chapter 6](../part-2/chapter-06.md).

**interpretive governance.** The location of emotional meaning in an act an agent performs, so that the meaning admits correctness, error, justification, revision, and responsibility. See [Chapter 9](../part-4/chapter-09.md).

**metaperception.** Awareness of one’s own bodily state; the process by which interoceptive activity becomes feeling. See [Chapter 9](../part-4/chapter-09.md).

**ontological collapse.** The conflation of physiological affect, feeling, and emotion into stages of a single process. See [Chapter 9](../part-4/chapter-09.md).

**semantic achievement.** The construction of meaning when an agent interprets semiotically available material under goal-relative constraints. See [Chapter 9](../part-4/chapter-09.md).

**semiotic availability.** The condition of material, such as a feeling, that is consciously available for interpretation but does not yet carry meaning. See [Chapter 9](../part-4/chapter-09.md).

**showstopper criterion.** A non-negotiable criterion in the trade study whose failure eliminates a candidate theory. See [Chapter 9](../part-4/chapter-09.md) and [Appendix I](../appendices/appendix-i.md).

**TCI.** See *Theory of Constrained Identity*.

**Theory of Constrained Identity (TCI).** The theory that identity conditions constrain admissible variation without eliminating flexibility. It separates four functions: conceptual identity (constraint), instantiation, categorization, and goal-directed evaluation. See [Chapter 6](../part-2/chapter-06.md).

**weighted score matrix (WSM).** The trade-study method that scores candidate theories against weighted definitional, analytic, cognitive-semiotic, and computational criteria. One rater set the scores. See [Chapter 9](../part-4/chapter-09.md) and Appendixes [G](../appendices/appendix-g.md)–[I](../appendices/appendix-i.md).

**WSM.** See *weighted score matrix*.
